# 👾 Game2D Alien

> Jogo 2D estilo Space Invaders desenvolvido em **Python** com **Pygame**.

[![Python](https://img.shields.io/badge/Python-3.11-3776AB?style=flat-square&logo=python&logoColor=white)](https://python.org)
[![Pygame](https://img.shields.io/badge/Pygame-2.5-4B0082?style=flat-square)](https://pygame.org)

---

## 🎮 Sobre o Jogo

Jogo de nave espacial onde o jogador deve destruir ondas de aliens antes que eles cheguem ao fundo da tela.

---

## 📁 Estrutura do Projeto

```
Game2D_Alien/
├── src/
│   ├── alien.py           # Classe do alien
│   ├── alien_invasion.py  # Classe principal do jogo
│   ├── bullet.py          # Classe dos tiros
│   ├── settings.py        # Configurações do jogo
│   └── ship.py            # Classe da nave
├── images/
│   ├── alien.bmp          # Sprite do alien
│   └── ship.bmp           # Sprite da nave
└── README.md
```

---

## 🚀 Como Executar

```bash
cd "1. Game2D_Alien"
python -m src.alien_invasion
```

**Requisitos:**
- Python 3.11+
- Pygame

```bash
pip install pygame
```
