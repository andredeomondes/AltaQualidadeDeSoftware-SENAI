## 📚 Sobre a Disciplina

Disciplina focada em **qualidade de software**, cobrindo tópicos como:
- Clean Code e boas práticas de programação
- Testes unitários e de integração
- Padrões de projeto (Design Patterns)
- Arquitetura de software
- DevOps e CI/CD
- Documentação e manutenibilidade

## 📁 Projetos

### 1. Game2D Alien

Jogo 2D desarrollado com **Python** utilizando a biblioteca **Pygame**.

| Característica | Detalhe |
|----------------|---------|
| **Linguagem** | Python 3.11 |
| **Framework** | Pygame |
| **Conceitos** | Programação de jogos, loops de jogo, sprites |
| **Status** | ✅ Concluído |

#### 🎮 Como Executar

```bash
cd "1. Game2D_Alien"
python main.py
```
